# Form Submission App - A Windows Applicaton

A simple Form Submission App made with the Windows Forms environment of Visual Studio 2026. This app was made for testing
the various functions of said environment and how they could be used to create a fully functional Form for submitting a request.

Below are listed some screenshots of said tested functionalities and features.

Firstly, the user has to enter their Tax Identification Number (TIN):

<img width="613" height="244" alt="image" src="https://github.com/user-attachments/assets/a94a0966-6464-45fa-831c-d157ad26db3d" />

Then, after a quick check of the validity of said TIN, the following fields will appear, so they can be filled:
<img width="622" height="328" alt="image" src="https://github.com/user-attachments/assets/67aff228-2735-409f-b6bd-9fa8235f153d" />

When the user has filled all the prerequisite fields, they have to press the button at the bottom right corner
to continue. The following window will then appear:
<img width="621" height="330" alt="image" src="https://github.com/user-attachments/assets/d0d00e37-485e-41e9-9abe-bf7a1eafb401" />

There, the user can fill up the text box with free text for their application request. They can
clear it up with the leftmost button or insert text from a file with the blue-texted button. Finally,
they can Submit their application form with the red-texted button at the bottom-center:
<img width="621" height="330" alt="image" src="https://github.com/user-attachments/assets/532a7f55-e089-447b-aaa6-3d3bbd07fcfe" />

A confirmation window will appear:

<img width="375" height="123" alt="image" src="https://github.com/user-attachments/assets/43ef76f9-4059-4cb9-911c-0180aec55af0" />

If the user pressed "No" at the confirmation window, the form will go back to the previous window.
If the user pressed "Yes", the final confirmation dialog will appear:
